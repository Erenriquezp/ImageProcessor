# Fixtures de E/S

`gradient-lossless.webp` y `gradient-lossy.webp`: degradado 32×24 generado por este proyecto (R = x·8, G = y·10, B = 90), con `webp-imageio` 0.3.3 (Apache-2.0) solo para crearlos. Sin material de terceros: contenido propio bajo la licencia del repositorio.

El resto de fixtures (ICC, EXIF, CMYK, 16 bits) se generan por código en los tests.
